An Agentic WhatsApp Bot
Built for Automation

A multi-account WhatsApp bot that handles everything from group commands and instant media downloads to an agentic AI that can search the web, write and run code, and deliver files. All through a single chat message.

View on GitHub Setup

Everything the bot can do

Multi-account, agentic, and built to be extended.

Agentic AI

Searches the web, writes and runs code, and delivers files, all triggered from a single chat message.

Multi-Account

Connects and runs multiple WhatsApp accounts at the same time from one deployment.

Instant Media Downloads

Pulls videos straight from supported platforms like TikTok, Instagram, Facebook, and YouTube.

MariaDB & Redis Backed

Reliable storage and caching under the hood, with a sandboxed shell environment for safe execution.

Hot-Reloading Commands

Extend the bot by dropping in a new file. No restart required.

Secure by Design

Integrated with Phishtank and VirusTotal to keep groups safe, plus rate limiting for end users.

Supported AI Providers

  • OpenRouter
  • OpenAI
  • Groq
  • Gemini (Google)
  • Ollama

Prerequisites

  • Node.js (>=18.x)
  • MySQL
  • Redis / Valkey
  • WhatsApp Account
  • Chrome browser
  • FFMPEG

Quick Start

npx project-canis

Run it instantly with NPX, no cloning or manual setup required.
